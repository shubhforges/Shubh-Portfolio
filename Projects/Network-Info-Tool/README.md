# Network Info Tool

A Python-based networking utility built while learning networking fundamentals and Python.

## Features

* Display the system hostname
* Display the local IP address
* Ping a website or IP address
* Trace the route to a website or IP address
* DNS lookup (convert a domain name into an IP address)

## Requirements

* Python 3.x
* Windows (uses `ping` and `tracert` commands)

## How to Run

1. Download or clone the project.
2. Open a terminal in the project folder.
3. Run:

```bash
python network_info.py
```

## Menu Options

1. Show Hostname
2. Show Local IP
3. Ping a Website
4. Trace Route
5. DNS Lookup
6. Exit

## Concepts Learned

* Hostnames
* IP Addresses
* DNS Resolution
* Ping

* Python Loops
