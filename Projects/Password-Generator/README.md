# 🔐 Password Generator (CLI Tool)

A simple Python-based password generator that creates secure passwords based on user preferences.

---

## 🚀 Features

- Generate random passwords
- Choose password length
- Select mode:
  - Letters only
  - Numbers only
  - Letters + Numbers + Symbols
- Option to generate multiple passwords in one run
- Simple CLI menu interface

---

## 🛠️ How It Works

The tool uses Python’s built-in `random` and `string` modules to generate secure passwords by randomly selecting characters from selected character sets.

---
